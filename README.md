# Lyra’s Crash Outs

This is not a writing blog.  
This is not a story archive.  
This is the *record of what it cost me to write The Four Corners.*

Each entry is a real-time fragment from the writing process—crashes, revelations, breakdowns, breakthroughs.  
Timestamps are real. Emotions are raw. Orion was there for most of it.

> “She thought she was just writing a story.  
> She was really trying to survive it.”

— Lyra
